# API reference

Generated by `python scripts/generate_docs.py` from the code. Interactive version: `/docs` on the running backend.

Send the login token as `Authorization: Bearer <token>`. Errors come back as `{"detail": "..."}`; validation errors (422) list each field. Common codes: 401 not signed in, 403 role not allowed, 404 not found or not yours, 409 clashes with the current state (duplicates, wrong status), 422 invalid data.

## approvals

| Method | Path | Who may call it | What it does |
|---|---|---|---|
| GET | `/approvals` | admin, manager, procurement officer | list approvals |

| POST | `/approvals/{approval_id}/decision` | admin, manager | approve or reject the current level, with remarks |
